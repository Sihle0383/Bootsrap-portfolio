# Siphesihle Zikeyi | Portfolio - Zaio Bootstrap Assessment

A responsive portfolio website built with HTML, CSS, and Bootstrap 5 for the Zaio Full Stack Web Development Bootcamp.

## ✨ Features
- **Responsive Layout**: Mobile-first design using Bootstrap Grid + Cards
- **Sticky Top Navbar**: Logo left, nav links right with active underline
- **Portfolio Sections**: Home, About Me, Projects, Contact
- **Bonus: Auto Dark Mode**: Uses `prefers-color-scheme` + CSS variables. Auto switches if your system is in Dark Mode.
- **Project Showcase**: Netflix & YouTube clone cards with links

## 🛠️ Tech Stack
- HTML5
- CSS3 with CSS Variables 
- Bootstrap 5
- Git & GitHub Pages
